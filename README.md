GitHub Copilot + Codespaces Skills Project
A guided demonstration of AI‑assisted development, devcontainers, and GitHub automation.

Overview
This project showcases how GitHub Copilot, Codespaces, and GitHub Actions work together inside a fully configured development environment. It began as a GitHub Skills exercise, but it has been refined to demonstrate practical developer workflows, AI‑assisted coding, and automated repository management.

The repository includes a complete devcontainer setup, step‑based GitHub Actions automation, and an example JavaScript module generated and refined with Copilot.

🧠 AI‑Assisted Development with GitHub Copilot
